# jogo

RPG idle de navegador (desktop e celular), online e multiplayer, com uma economia movida pelos jogadores.

O projeto terminou pesquisa, conceito, design (GDD) e arquitetura. Ainda não há código do jogo, por decisão de processo: a construção começa na Fase 5, depois do checkpoint da arquitetura. O único código até aqui é a simulação da economia.
